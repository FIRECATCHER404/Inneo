# Inneo

A native Windows IDE with support for multiple languages, customizable syntax highlighting, and Python/C/C++ editor tools and debugging.

**[Download Inneo for Windows](https://github.com/FIRECATCHER404/Inneo/releases/latest)**

Requires 64-bit Windows 10 or 11. Extract the complete ZIP and run `Inneo.exe`; keep the bundled folders beside it. Python and the editor tools are included. Other language toolchains, and GDB for C/C++ debugging, are installed separately.

Third-party notices and licenses are included in the download.
